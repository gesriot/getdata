# GetData

Программа оцифровки графиков на Rust (eframe/egui 0.37). Читает и пишет воркспейсы `.gdw`
и экспортирует данные в форматы GetData.

## Сборка и запуск

```
cargo build --release
target\release\getdata.exe [файл.gdw | изображение]
```

Тесты: `cargo test`.

## Возможности

* Пиксели → координаты: неортогональные оси, логарифмические шкалы.
* Классификатор «линия/фон» (YCbCr, 3 метода), поиск центра линии по клику.
* Автотрассировка: окружность Брезенхема, дуги, фильтр угла и веса, сглаживание кубическим МНК по 5 точкам.
* Оцифровка области: повёрнутая сетка / сетка по осям, центр или границы.
* Автоопределение цветов линии и фона, упорядочивание точек.
* Воркспейс `.gdw` (XML, координаты в 1/9 пикселя, `MF="9"`).
* Экспорт: TXT/буфер обмена (0.001, 1e-003, Mathematica), XLS (BIFF2), XML (Excel 2003), EPS, DXF R12.
* Интерфейс на английском и русском.

## Дополнительно

* Новые форматы экспорта: **XLSX** (OPC-пакет по образцу GridCraft) и **DXF R2000/AC1015**
  (структура по образцу CADCraft: слой на каждую линию с её цветом, LWPOLYLINE/POINT).
  Старые XLS (BIFF2), XML и DXF R12 оставлены. DXF проверены `cadcraft-cli` (включая
  конвертацию в DWG) и аудитом `ezdxf`, XLSX – `gridcraft-cli check`, XLS – `xlrd`.
* Трассировка «во все стороны» складывает две ветви в непрерывную полилинию.
* Удаление линий и всех данных отменяется через Undo.
* Дополнительно читаются PNG и GIF; файлы можно перетаскивать в окно.
* Ctrl в режиме установки точек ставит точку с субпиксельной точностью.

## Структура

```
src/main.rs      запуск, иконка окна
src/app.rs       состояние и операции
src/ui.rs        меню, панель инструментов, строка состояния, горячие клавиши
src/canvas.rs    изображение, сетка, оси, точки, мышь по режимам
src/panels.rs    окно информации (состояние / данные), лупа
src/dialogs.rs   диалоги
src/digitize.rs  алгоритмы оцифровки
src/coords.rs    система координат
src/gdw.rs       воркспейс .gdw
src/export.rs    экспорт; xlsx.rs, dxf.rs – XLSX и DXF R2000
src/imageio.rs   загрузка изображений (+ свой декодер PCX)
src/i18n.rs      English / Русский
src/icons.rs     векторные значки
assets/aci.bin   стандартная палитра AutoCAD ACI
```
