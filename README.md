# GetData

Программа оцифровки графиков на Rust (eframe/egui 0.37). Читает и пишет воркспейсы `.gdw`
и экспортирует данные в форматы GetData.

## Возможности

* Пиксели → координаты: неортогональные оси, логарифмические шкалы
* Классификатор «линия/фон» (YCbCr, 3 метода), поиск центра линии по клику
* Автотрассировка: окружность Брезенхема, дуги, фильтр угла и веса, сглаживание кубическим МНК по 5 точкам
* Оцифровка области: повёрнутая сетка / сетка по осям, центр или границы
* Автоопределение цветов линии и фона, упорядочивание точек
* Воркспейс `.gdw` (XML, координаты в 1/9 пикселя, `MF="9"`)
* Экспорт: TXT/буфер обмена (0.001, 1e-003, Mathematica), XLS (BIFF2), XML (Excel 2003), EPS, DXF R12
* Интерфейс на английском и русском

## Дополнительно

* Новые форматы экспорта: **XLSX** (OPC-пакет по образцу GridCraft) и **DXF R2000/AC1015**
  (структура по образцу CADCraft: слой на каждую линию с её цветом, LWPOLYLINE/POINT)
  Старые XLS (BIFF2), XML и DXF R12 оставлены. DXF проверены `cadcraft-cli` (включая
  конвертацию в DWG) и аудитом `ezdxf`, XLSX – `gridcraft-cli check`, XLS – `xlrd`
* Трассировка «во все стороны» складывает две ветви в непрерывную полилинию
* Удаление линий и всех данных отменяется через Undo
* Дополнительно читаются PNG и GIF; файлы можно перетаскивать в окно
* Ctrl в режиме установки точек ставит точку с субпиксельной точностью

## Структура

```
src/main.rs      запуск, иконка окна
src/app.rs       состояние и операции
src/ui.rs        меню, панель инструментов, строка состояния, горячие клавиши
src/canvas.rs    изображение, сетка, оси, точки, мышь по режимам
src/panels.rs    окно информации (состояние / данные), лупа
src/dialogs.rs   диалоги
src/digitize.rs  алгоритмы оцифровки
src/coords.rs    система координат
src/gdw.rs       воркспейс .gdw
src/export.rs    экспорт; xlsx.rs, dxf.rs – XLSX и DXF R2000

src/i18n.rs      English / Русский
src/icons.rs     векторные значки
assets/aci.bin   стандартная палитра AutoCAD ACI
```
## Сборка и запуск

```
cargo build --release
target\release\getdata.exe [файл.gdw | изображение]
```

### Windows: сборка с иконкой

```powershell
.\scripts\package-windows.ps1
```

Нужны Rust MSVC, Windows SDK (`rc.exe`) и Python с Pillow (`python -m pip install Pillow`).
Скрипт использует готовую прозрачную иконку `macos/icon-runtime.png`, создаёт ICO
с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей и встраивает её в `.exe`,
чтобы она отображалась в Проводнике, ярлыках и на панели задач.
Обычный `cargo build --release` задаёт только иконку окна.

Результат: `dist/windows/GetData.exe`, лицензия рядом и архив `dist/GetData-windows.zip`.
Отдельная иконка: `target/windows-package/app.ico`.
Параметр `-NoZip` отключает архив, `-Target x86_64-pc-windows-msvc` явно задаёт целевую платформу.
`-SkipBuild` копирует ранее собранный исполняемый файл; он должен быть предварительно
собран этим скриптом, чтобы сохранить встроенную иконку.

### macOS: приложение с иконкой и DMG

Сборку нужно запускать в macOS. Нужны Rust, Xcode Command Line Tools
и Python 3 с Pillow (`python3 -m pip install Pillow`)

```bash
bash ./scripts/package-macos.sh
```

Скрипт обрабатывает исходную иконку `assets/icon.png`: убирает внешний фон,
скругляет углы и создаёт `macos/icon-rounded.png`, `macos/icon-runtime.png`
для окна и Dock и `macos/icon.icns` для приложения. Затем выполняет
`cargo build --release` и создаёт:

* `dist/GetData.app` – приложение с иконкой;
* `dist/GetData.app.zip` – ZIP-архив приложения;
* `dist/GetData.dmg` – образ для установки, проверенный через `hdiutil verify`.

Для установки откройте DMG и перетащите GetData в `Applications`.
Параметр `--skip-build` упаковывает ранее собранный `target/release/getdata`.
После изменения исходной иконки запускайте скрипт без этого параметра,
чтобы обновить также встроенную иконку окна и Dock.
Переменные окружения `ICON_PNG` и `DIST_DIR` позволяют задать другую исходную
иконку и каталог результата.
